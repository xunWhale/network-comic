幕一
反掩码揭秘

为什么 OSPF 要用反掩码？

子网掩码用来划分子网边界；OSPF 的 network 命令其实是个“接口筛选器”——用 0 锁死必须一样的位，用 1 放行随便啥都行的位。

最常见写法：0.0.0.0 精确锁死单个接口 IP；0.0.0.3 匹配 /30 互联点对点网段；0.0.0.255 匹配 /24 网段。

反掩码不是给路由表算掩码，是“圈人进 OSPF”

你在 OSPF 进程里敲 network 192.168.12.0 0.0.0.3，不是直接往外发这条路由，而是告诉路由器：“检查本机所有接口，谁的 IP 符合这个条件，就把那个接口拉进 Area 0 干活！”

新手最常见失误：把反掩码写成了正掩码 255.255.255.0——前 24 位全成了 1（通配），反而只锁死了最后 8 位，接口根本进不去 OSPF！

OSPF 反掩码实时计算器

正掩码：255.255.255.0
反掩码：0.0.0.255
网络号：192.168.1.0

前缀正掩码OSPF 反掩码
/32255.255.255.2550.0.0.0（锁死单接口）

偷懒神技：哪怕接口掩码是 /24 或 /30，写 network 接口IP 0.0.0.0 也绝对不会错——精准命中这一个接口！
幕二
环回口稳定

配置 OSPF 需不需要配环回口？

答：不是语法强制，但工程上强烈建议配！ 物理口拔掉网线就会 Down，而 Loopback 只要路由器通着电就永远 UP，是 OSPF 身份证（Router-ID）的定海神针。

物理线会松、光模块会坏；Loopback 存在内存里，是路由器永不宕机的名片。

为什么老网工都要顺手建一个 Loopback 0？

第一，身份证稳：OSPF 全网靠 Router-ID 认设备，用环回口永不震荡；第二，双线不掉管理：哪怕下面两条物理链断了一条，只要 OSPF 还连通，直接 ping 1.1.1.1 照样通；第三，为 BGP 打基础：后面学 IBGP 建邻居几乎全靠 Loopback！

Router-ID 选举规则

不手工指定，路由器怎么给自己起名字？

优先级来源工程建议
第 1 顺位手工配 router-id 1.1.1.1最稳！全网不会撞号
第 2 顺位所有 Loopback 中最大 IP没手工配时优先挑环回口
第 3 顺位物理 UP 接口中最大 IP物理口一断就容易出问题
✓
一句话给刚做实验的你：如果只连两台路由器测试连通性，不配 Loopback 只配物理接口也能建起 Full 邻居；但按规范实验（比如 eNSP 拓扑题），把 LoopBack 0 配成 1.1.1.1/32、再手工指定 ospf 1 router-id 1.1.1.1 并宣告进 area 0，排错和测试都爽十倍！
小提示：改了 Router-ID 后不会立刻生效，在华为设备上要在用户视图敲 <R1> reset ospf process 重启一下 OSPF 进程。
幕三
建邻七状态

邻居卡在哪一步，一查就知道怎么修。

OSPF 从发 Hello 到算出完整地图要走 7 步。平时查命令看到 Full 才算彻底建好；卡在半路十有八九是参数没对上。

卡在 Init 多半单向不通；卡在 ExStart 多半两端 MTU 不一致；全是空白多半 Area 或反掩码错了。

先交朋友（2-Way），再对账本（Full）

OSPF 路由器不像 RIP 那样把路由表到处广播，而是先把整个区域里的链路拓扑同步成一模一样的地图（LSDB），然后各家自己用 SPF 算法算最短路。

幕四
eNSP 实战

华为路由器两机直连，照抄就能 Full。

先配 Loopback 0 和直连接口 IP，再启动 OSPF 指定 Router-ID 并用反掩码宣告接口。配完互 ping 对方环回口 ping -a 1.1.1.1 2.2.2.2 验证。

左侧 R1 配置

Loopback 0 + Area 0 宣告

# 1. 配环回口与物理接口
[R1] interface LoopBack 0
[R1-LoopBack0] ip address 1.1.1.1 32
[R1-LoopBack0] interface GigabitEthernet 0/0/0
[R1-GigabitEthernet0/0/0] ip address 192.168.12.1 255.255.255.252
[R1-GigabitEthernet0/0/0] quit

# 2. 启动 OSPF 并指定稳定的 Router-ID
[R1] ospf 1 router-id 1.1.1.1
[R1-ospf-1] area 0.0.0.0
[R1-ospf-1-area-0.0.0.0] network 192.168.12.0 0.0.0.3
[R1-ospf-1-area-0.0.0.0] network 1.1.1.1 0.0.0.0
细节：1.1.1.1 0.0.0.0 把 R1 的环回口也通告进 OSPF，这样 R2 就能在路由表里学到 1.1.1.1/32！
右侧 R2 配置与验货

对端宣告 + 查看 Full 邻居

[R2] interface LoopBack 0
[R2-LoopBack0] ip address 2.2.2.2 32
[R2-LoopBack0] interface GigabitEthernet 0/0/0
[R2-GigabitEthernet0/0/0] ip address 192.168.12.2 255.255.255.252
[R2-GigabitEthernet0/0/0] quit

[R2] ospf 1 router-id 2.2.2.2
[R2-ospf-1] area 0
[R2-ospf-1-area-0.0.0.0] network 192.168.12.2 0.0.0.0
[R2-ospf-1-area-0.0.0.0] network 2.2.2.2 0.0.0.0

# 3. 验证邻居达到 Full 且学到对端 Loopback
<R1> display ospf peer brief
  Area Id       Interface       Neighbor id    State
  0.0.0.0       GE0/0/0         2.2.2.2        Full
你看：R1 写网段反掩码 192.168.12.0 0.0.0.3，R2 写精准单口 192.168.12.2 0.0.0.0，照样能建起 Full 邻居！
记住：反掩码圈接口，环回口稳身份，Hello 握手成 Full。
