两台 PC 隔着三台路由器（4 个网段），为什么配好了去程还是 Ping 不通？点下面四个模式，直接看清包在每一跳怎么走、翻车又死在哪。

第一部分 · 选型对比

同一张拓扑，静态路由和 OSPF 思路差在哪？

小拓扑两条都能通，差别在于：静态路由是“人肉给每台路由器画好去程+回程路牌”，OSPF 是“每台只报自己直连的网段，大家自动算全图”。

方案 A · 静态路由

手写远端网段 + 对端下一跳

少写任何一条回程，包到得了 PC2 却回不来，Ping 直接超时

直连网段路由器天生认识，不用写。你只需要把不直连的远端网段，逐台写清楚“下一跳是对端的哪个接口 IP”。

口诀：永远填“对面接口 IP”，不要填自己本地出接口 IP。
方案 B · OSPF Area 0

只宣告自己的直连网段，邻居自动全网通

不要把别人的网段塞进自己的 network，管好自己直连的两段就行

每台路由器进 ospf 1 → area 0，用 network 网段 反掩码 把直连接口放进 OSPF，Full 建邻后去程回程自动生成。

反掩码：/24 用 0.0.0.255，/30 用 0.0.0.3，或者直接用 接口IP 0.0.0.0。
第二部分 · 完整命令

直接复制进华为 eNSP：静态路由 vs OSPF 完整配置

先给三台路由器接口配好 IP，再二选一贴入下面左侧（静态）或右侧（OSPF）命令；别忘了在 PC1 / PC2 填好网关！

方案 A · 静态路由完整 CLI

AR1 / AR2 / AR3 双向静态路由

# --- AR1 (去 PC2 与 AR2-AR3 段) ---
[AR1] ip route-static 192.168.2.0 24 10.0.12.2
[AR1] ip route-static 10.0.23.0 30 10.0.12.2

# --- AR2 (中间节点：左右两头都要写!) ---
[AR2] ip route-static 192.168.1.0 24 10.0.12.1
[AR2] ip route-static 192.168.2.0 24 10.0.23.2

# --- AR3 (回 PC1 与 AR1-AR2 段) ---
[AR3] ip route-static 192.168.1.0 24 10.0.23.1
[AR3] ip route-static 10.0.12.0 30 10.0.23.1

验证：用 display ip routing-table 检查每台都有对方 LAN 网段，且下一跳是对端接口 IP。

方案 B · OSPF 完整 CLI

AR1 / AR2 / AR3 只宣告直连网段

# --- AR1 ---
[AR1] ospf 1 router-id 1.1.1.1
[AR1-ospf-1] area 0
[AR1-ospf-1-area-0.0.0.0] network 192.168.1.0 0.0.0.255
[AR1-ospf-1-area-0.0.0.0] network 10.0.12.0 0.0.0.3

# --- AR2 ---
[AR2] ospf 1 router-id 2.2.2.2
[AR2-ospf-1] area 0
[AR2-ospf-1-area-0.0.0.0] network 10.0.12.0 0.0.0.3
[AR2-ospf-1-area-0.0.0.0] network 10.0.23.0 0.0.0.3

# --- AR3 ---
[AR3] ospf 1 router-id 3.3.3.3
[AR3-ospf-1] area 0
[AR3-ospf-1-area-0.0.0.0] network 10.0.23.0 0.0.0.3
[AR3-ospf-1-area-0.0.0.0] network 192.168.2.0 0.0.0.255

验证：用 display ospf peer brief 看 State 是否全部达到 Full。

第三部分 · 排错清单

为什么配完还是 Request time out？先查这四坑

实验连通率翻车 90% 出在下面四件事：缺回程、下一跳填自己、反掩码填反、PC 没填网关。

翻车点 1

只配了去程，漏写 AR3/AR2 回程路由

Echo Request 顺利到达 PC2，PC2 回复时 AR3 查不到 192.168.1.0/24 直接丢包。用 display ip routing-table 在 AR3 上一眼就能看出缺条目。

翻车点 2

下一跳填成“本地出接口 IP”

在 AR1 配去 192.168.2.0/24 的路由时，下一跳必须写对面 AR2 的 10.0.12.2，千万别写成自己的 10.0.12.1。

翻车点 3

OSPF 反掩码写反，或者宣告了对端网段

掩码 255.255.255.0 的反掩码是 0.0.0.255；每台路由器只 network 自己直连的两个网段。用 display ospf peer brief 看邻居是否 Full。

翻车点 4

PC 忘配网关，或者接口处于 DOWN

PC1 必须填 192.168.1.1，PC2 必须填 192.168.2.1；路由器上用 display ip interface brief 确认每个用到的口都是 up / up。
