# 小鲸鱼的数通小剧场：路由器与下一跳的秘密

写给**刚学完静态路由、但还没搞明白为什么这么配**的人。

不讲命令，先讲画面：把一次跨网段通信想成赛博快递站里的一件包裹——终点地址不变，沿途每一站换车牌，路由器只负责把它交给下一位小哥。

## 四幕

| 幕 | 讲什么 | 一句话 |
| --- | --- | --- |
| 一 | IP 与 MAC 的分工 | IP 找终点，MAC 找这一站 |
| 二 | 路由表与下一跳 | 路由表不是地图，是分拣员的派件清单 |
| 三 | 子网掩码与最长匹配 | 把地址切成「区域 + 门牌号」 |
| 四 | 静态路由命令 | 命令就是给路由器立一块路标 |

首屏点「发包裹」，可以看到数据包从 PC1 经 R1、R2 到 PC2：**目的 IP 全程不变，MAC 每跳重新封装**。
