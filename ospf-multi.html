第五弹 · 多区域 OSPF 与 ABR 实战

一个骨干区，两个非骨干区，谁来翻译？

三台 PC 分在三个网段，路由器分在两个 OSPF 区域。点下面的按钮，看清楚 AR2 这台 ABR 到底在哪一侧宣告什么网段，以及为什么三台 PC 最后能互通。

AR2 同时属于 Area 0 和 Area 1，把 192.168.1.0/24 转告 Area 1，把 192.168.2.0/24 和 192.168.3.0/24 转告 Area 0，三台 PC 互通
核心：ABR 必须在骨干区 Area 0 里有至少一个完全建邻的接口，否则它转发的跨区路由会被拒绝。
eNSP 多区域拓扑 · Area 0 / Area 1 三网段互通
第一部分 · 为什么要分区

OSPF 分区的两条铁律：非骨干区域必须挂在 Area 0 上

单个区域里每台路由器都要算整张拓扑。区域一大，LSDB 爆炸、SPF 重算频繁。分区就是「把一个大地图切成几个小地图，只在边界交换摘要」。

铁律一 · 骨干区不可少

Area 0 是中枢，所有区域间的流量都从它过

非骨干区域之间不允许直接交换 LSA。Area 1 要知道 Area 2 的路由，必须经 ABR 转成 Type-3 摘要，再由骨干区带过去。

路由器角色接口所在区
AR1内部路由器（IR）Area 0
AR2区域边界路由器（ABR）Area 0 + Area 1
AR3 / AR4内部路由器（IR）Area 1
铁律二 · ABR 要有骨干连接

ABR 必须在 Area 0 里建过邻，否则跨区路由被拒

ABR 的门槛不是「配置里写了 area 0」，而是在 Area 0 里至少有一个 Full 状态的邻居。没有这条虚拟连接，它发出的 Type-3 会被骨干区路由器丢弃。

!
常见翻车：把 AR2 的两个接口都塞进 Area 1，再指望它转告 Area 0 的路由 —— 它此时只是个 IR，转不动。
口诀：一台路由器属于哪个区，是按接口算的，不是按设备算的。
第二部分 · 完整命令

照着这张拓扑抄：四台路由器怎么宣告

先配接口 IP 和 PC 网关，再按下面的顺序进 OSPF。注意 AR2 要分两次进 area，这是唯一和单区域写法不同的一台。

左侧 · Area 0

AR1：只属于骨干区

# 接口与网关
[AR1] interface GigabitEthernet0/0/0
[AR1-GigabitEthernet0/0/0] ip address 192.168.1.254 24
[AR1] interface Serial4/0/0
[AR1-Serial4/0/0] ip address 10.0.12.1 24

# OSPF：两个直连网段都进 area 0
[AR1] ospf 1 router-id 1.1.1.1
[AR1-ospf-1] area 0
[AR1-ospf-1-area-0.0.0.0] network 192.168.1.0 0.0.0.255
[AR1-ospf-1-area-0.0.0.0] network 10.0.12.0 0.0.0.255

PC1 网关填 192.168.1.254。

中间 · ABR

AR2：左边进 0，右边进 1

# 接口
[AR2] interface Serial4/0/0
[AR2-Serial4/0/0] ip address 10.0.12.2 24
[AR2] interface GigabitEthernet0/0/0
[AR2-GigabitEthernet0/0/0] ip address 10.0.234.1 24

# 关键：两次 area，各宣告各的
[AR2] ospf 1 router-id 2.2.2.2
[AR2-ospf-1] area 0
[AR2-ospf-1-area-0.0.0.0] network 10.0.12.0 0.0.0.255
[AR2-ospf-1] area 1
[AR2-ospf-1-area-0.0.0.1] network 10.0.234.0 0.0.0.255

不要把 10.0.12.0 和 10.0.234.0 写进同一个 area。

第三部分 · MA 网络里的 DR/BDR

三台路由器挂在同一个交换机上，谁跟谁建邻？

Area 1 这段是多路访问（MA）网络：AR2、AR3、AR4 都在 10.0.234.0/24 里。如果不选 DR，三台两两建邻就要 3 条邻接；四台要 6 条，八台要 28 条。

选举规则

先比优先级，再比 Router-ID

比较项默认值结果
接口优先级1大者当选 DR
Router-ID手工配置优先级相同时大者胜
优先级 0—放弃参选

在我们的图里：AR2 的 RID 是 2.2.2.2，AR3 是 3.3.3.3，AR4 是 4.4.4.4，优先级都是默认 1 —— 于是 AR4 当 DR，AR3 当 BDR，AR2 是 DROther。

验证与调优

看邻居状态，必要时手动指定

# 看邻居关系：DROther 之间是 2-Way，其它是 Full
[AR2] display ospf peer brief

# 手动让 AR2 当 DR（优先级调大）
[AR2] interface GigabitEthernet0/0/0
[AR2-GigabitEthernet0/0/0] ospf dr-priority 100

# 改完要重启 OSPF 进程才会重新选举
[AR2] reset ospf process

注意：DR 选举不是抢占式的。调完优先级后，只有重启进程或邻居重建才会重新选。

✓
三台 PC 互通的判定顺序：① 每台 PC 网关填对 → ② Area 0 里 AR1↔AR2 是 Full → ③ Area 1 里 AR2/AR3/AR4 邻居起来 → ④ display ip routing-table 在 AR1 上能看到 .2.0 和 .3.0 两条 OSPF 路由 → ⑤ PC1 ping PC2、PC3 都通。
